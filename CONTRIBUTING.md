# Contributing

Thank you for helping improve Awesome AI Evals. This list aims to be concise,
useful, and trustworthy.

## Suggesting a resource

Submit a pull request that adds the resource to the most appropriate category
in `README.md`. Before submitting, check the existing list for duplicates and
confirm that the resource is directly relevant to AI evaluation.

Every resource must use this format:

```markdown
- [Resource Name](URL) — Short, factual description explaining what it is and
  why it is useful. `Type` · `License/Access`
```

Use a canonical URL where possible. The description should be concise,
specific, and non-promotional. Do not rank resources by popularity or GitHub
stars. Mention important limitations when they affect how the resource should
be used.

## Reporting a broken link

Open an issue or submit a pull request with the affected resource, the URL, and
a brief description of the problem. If a maintained canonical URL is
available, include it in the proposed change.

## Review process

Maintainers review submissions for relevance, quality, duplication, factual
accuracy, link availability, and fit with the repository structure. They may
request changes before merging. Promotional, duplicate, outdated,
unverifiable, or low-quality links may be rejected.

Contributors must verify that URLs work and that all factual claims in their
descriptions are accurate. By contributing, you agree that your contributions
are provided under the repository's [CC0 1.0 license](LICENSE).
