## 2. Evaluation Metrics

| Term | Meaning | Priority |
| --- | --- | --- |
| Accuracy | Fraction of predictions that are correct. | 🔴 Must know |
| Precision | Fraction of predicted positives that are actually positive. | 🔴 Must know |
| Recall | Fraction of actual positives correctly identified. | 🔴 Must know |
| F1 Score | Harmonic mean of precision and recall. | 🔴 Must know |
| F-beta Score | Weighted harmonic mean emphasizing precision or recall. | 🟠 Important |
| True Positive (TP) | Correctly predicted positive. | 🔴 Must know |
| True Negative (TN) | Correctly predicted negative. | 🔴 Must know |
| False Positive (FP) | Incorrectly predicted positive. | 🔴 Must know |
| False Negative (FN) | Incorrectly predicted negative. | 🔴 Must know |
| Confusion Matrix | Table comparing actual and predicted labels. | 🔴 Must know |
| Sensitivity | Another name for recall. | 🔴 Must know |
| Specificity | Fraction of actual negatives correctly identified. | 🟠 Important |

| False Negative Rate | Fraction of actual positives incorrectly classified negative. | 🟠 Important |
| Exact Match (EM) | Whether the prediction exactly matches the reference. | 🔴 Must know |
| Token F1 | Token-level overlap between prediction and reference. | 🟠 Important |
| Pass Rate | Percentage of tasks completed successfully. | 🔴 Must know |
| pass@k | Probability that at least one of k generated attempts succeeds. | 🔴 Must know |

| Tie Rate | Fraction of comparisons producing a tie. | 🟠 Important |
| Elo Rating | Relative skill rating updated using pairwise outcomes. | 🟠 Important |
| Bradley–Terry Model | Statistical model estimating strengths from pairwise preferences. | 🟠 Important |
| Mean Reciprocal Rank (MRR) | Average reciprocal rank of the first relevant result. | 🟠 Important |
| Precision@k | Relevant items among the top k retrieved items. | 🔴 Must know |
| Recall@k | Relevant items retrieved in the top k divided by all relevant items. | 🔴 Must know |
| Hit Rate@k | Fraction of queries with at least one relevant result in the top k. | 🔴 Must know |
| NDCG | Ranking metric accounting for relevance and position. | 🟠 Important |
| Mean Average Precision (MAP) | Mean of average precision values across queries. | 🟠 Important |
| BLEU | N-gram overlap metric historically used for translation. | 🟠 Important |
| ROUGE | Overlap-based metric frequently used in summarization evaluation. | 🟠 Important |

| Cross-Entropy | Loss measuring discrepancy between predicted probabilities and targets. | 🟠 Important |
| Calibration Error | Difference between predicted confidence and observed accuracy. | 🟠 Important |
| Brier Score | Mean squared error of probabilistic predictions. | 🟠 Important |
| AUROC | Area under the receiver operating characteristic curve. | 🟠 Important |
| AUPRC | Area under the precision–recall curve. | 🟠 Important |
| Composite Score | Score combining multiple metrics. | 🔴 Must know |
| Weighted Score | Metric giving different importance to different examples or criteria. | 🔴 Must know |
| Macro Average | Average of per-group metrics with equal group weight. | 🔴 Must know |
| Micro Average | Aggregation across individual examples or decisions. | 🔴 Must know |
| Task Success Rate (TSR) | Percentage of tasks that reach the required outcome. | 🔴 Must know |
| Completion Rate | Fraction of tasks or workflows completed. | 🔴 Must know |
| Partial Credit | Score awarded for partially satisfying a task. | 🟠 Important |
| Cost per Success | Total evaluation or inference cost divided by successful tasks. | 🟠 Important |
| Pareto Frontier | Set of solutions not dominated across competing objectives. | 🟠 Important |

**Key distinction:** `pass@k` measures whether at least one of k attempts
succeeds; `pass^k` measures success across all k repeated attempts and is
useful for evaluating agent reliability.
